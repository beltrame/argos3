# DARPA SubT Urban Circuit Practice 01

The "Urban Circuit Practice 01" world of the DARPA Subterranean
Challenge, published by Open Robotics on
[Gazebo Fuel](https://app.gazebosim.org/OpenRobotics/fuel/worlds/Urban%20Circuit%20Practice%2001),
imported as a photorealism environment: 33 urban tiles (service rooms,
two-storey halls, a stairwell, elevation changes, bends, blockers) on
three levels, plus the staging area, base station and the scattered
SubT artifacts (backpacks, phones, vents, Rescue Randy).

|                      |                                                  |
|----------------------|--------------------------------------------------|
| Extent (SDF frame)   | x [-149.8, 148.3], y [-213.9, 45.5], z [-29.1, 26.1] m |
| Staging area         | metro platform, floor z = 7.5 around the base station at (1, 27) |
| First lit tile       | service room at (-96, -16), floor z = 1.0         |
| Placements           | 56 includes, 31 distinct Fuel models              |
| Visual triangles     | 1.81 M in 436 nodes                               |
| Collision triangles  | 1.81 M (same meshes; Jolt doubles them by default) |
| Lights               | 35 SDF spot lights, ceiling downlights            |

## Files

Generated by `../import_fuel_world.py` and **not committed** (the two
glTF files are ~70 MB); regenerate them with:

```sh
python3 -m venv /tmp/fuel-venv
/tmp/fuel-venv/bin/pip install trimesh pycollada numpy pillow
cd src/plugins/simulator/photorealism/environments
/tmp/fuel-venv/bin/python import_fuel_world.py \
    "OpenRobotics/worlds/Urban Circuit Practice 01" --out .
```

The first run downloads ~500 MB of Fuel models into
`~/.cache/argos3-fuel`; later runs are offline and take about two
minutes.

| File                                    | Use                                                      |
|-----------------------------------------|----------------------------------------------------------|
| `urban_circuit_practice_01.glb`         | `<scenery><prop model=... orientation="0,0,90" />`       |
| `urban_circuit_practice_01.collision.glb` | `<mesh id="world" file=... />` (Jolt)                  |
| `urban_circuit_practice_01.lights.xml`  | the `<lights>` block, to paste into a `<photorealism>`   |
| `urban_circuit_practice_01.argos`       | runnable stand-alone tour (committed, generated)         |
| `urban_circuit_practice_01.json`        | bounds, per-tile placements, light list                  |

## Running

```sh
cd src/plugins/simulator/photorealism/environments/urban_circuit_practice_01
argos3 -c urban_circuit_practice_01.argos       # interactive viewer
mkdir -p frames && argos3 -z -c urban_circuit_practice_01.argos   # headless, PNGs in frames/
```

Asset paths in the experiment are relative to the experiment file (both
the `<mesh>` entity and the photorealism medium fall back to that
directory), so it also runs from anywhere with
`argos3 -c <path>/urban_circuit_practice_01.argos`.

To use the environment in an experiment, copy the `<mesh>` entity, the
`<photorealism>` medium (sun off, black sky, exposure, lights, prop)
and the Jolt physics engine from the generated file, then add robots.
Floor heights, measured with Jolt ray casts through the collision
mesh: the staging platform is at z = 7.5 (the base station stands on
it at (1, 27, 7.5)); tile floors are at the tile origin height, z = 1
on the upper level and z = -9 on the lower one, with the elevation
tiles in between. A foot-bot dropped at (-93, -18.5, 1.3) settles at
z = 1.000.

## Conversion notes

- SDF poses compose as world include -> nested include (the "Lights"
  tiles wrap the bare tile) -> link -> visual -> mesh scale -> COLLADA
  node; the COLLADA files are in centimetres (`Urban Elevation Up` is
  Y-up), which the importer converts.
- Visuals select COLLADA submeshes by node name; materials come from
  the SDF `<pbr><metal>` maps (albedo, normal, roughness and metalness
  packed into one metallic-roughness texture, emissive on the light
  domes). The tiles share their textures through the `Urban Platform`
  Fuel model; textures are downscaled to 1024 px.
- SDF has no photometric units. Every spot light gets 40000 lm at the
  SDF range (20 m) and its cone angles halved (SDF full angles ->
  Filament half-angles); the generated exposure is 10 stops above
  sunny 16 (f/2, 1/25 s, ISO 400), which renders the lit service rooms
  at a mean luminance of 0.24. Tune `--lumens` and `--stops` together.
  Tiles without a "Lights" variant (and the staging area) are dark, as
  in the competition, where the robots carried their own lamps.
- The scene is single-sided like the source: the tiles are hollow
  shells meant to be seen from inside.
