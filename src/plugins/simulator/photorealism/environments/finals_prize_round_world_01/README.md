# DARPA SubT Finals Prize Round World 01

The first prize-round world of the DARPA Subterranean Challenge Finals
(September 2021), published by Open Robotics on
[Gazebo Fuel](https://app.gazebosim.org/OpenRobotics/fuel/worlds/Finals%20Prize%20Round%20World%2001),
imported as a photorealism environment: a tunnel-circuit map of 401
placements (rough and constrained tunnel tiles, 4-way intersections,
vertical shafts, ramps, rail tunnels, rock falls, debris) entered from
the Finals staging area, with the SubT artifacts scattered through it.

|                      |                                                  |
|----------------------|--------------------------------------------------|
| Extent (SDF frame)   | x [-32.9, 416.7], y [-94.8, 114.8], z [-17.9, 14.6] m |
| Staging area         | industrial hangar at (-13, 0), floor z = 0       |
| Placements           | 401 includes, 35 distinct Fuel models             |
| Visual triangles     | 3.66 M in 1738 nodes                              |
| Collision triangles  | 1.35 M (tiles ship lower-poly colliders)          |
| Lights               | 88 SDF lights (72 spot, 16 point): staging area and 25 lit tiles |

## Files

Generated by `../import_fuel_world.py` and **not committed** (the glTF
files are ~60 MB); regenerate them with:

```sh
python3 -m venv /tmp/fuel-venv
/tmp/fuel-venv/bin/pip install trimesh pycollada numpy pillow
cd src/plugins/simulator/photorealism/environments
/tmp/fuel-venv/bin/python import_fuel_world.py \
    "OpenRobotics/worlds/Finals Prize Round World 01" --out .
```

| File                                       | Use                                                 |
|--------------------------------------------|-----------------------------------------------------|
| `finals_prize_round_world_01.glb`          | `<scenery><prop model=... orientation="0,0,90" />`  |
| `finals_prize_round_world_01.collision.glb` | `<mesh id="world" file=... />` (Jolt)              |

## Running

```sh
argos3 -c finals_prize_round_world_01.argos      # viewer, starts in the staging area
argos3 -z -c finals_prize_round_world_01.argos   # headless, PNGs in frames/
```

## Headlights

Unlike the Urban practice world, almost all of this map is unlit: only
the staging area and the `... Lights` tile variants carry SDF lamps.
The competition robots carried their own lights, and so can ARGoS
robots here: a `<lights>` entry with `entity="<robot id>"` is mounted
on that robot and follows it every tick, with `position` and
`direction` in the robot's body frame (+x forward, +z up):

```xml
<spot id="sp0"><body position="-18.08,99,-9.9" orientation="90,0,0" /> ... </spot>
...
<lights>
  <spot entity="sp0" position="0.5,0,0.25" direction="1,0,-0.15"
        intensity="3000" falloff="25" inner_angle="20" outer_angle="35"
        color="1.0,0.95,0.85" />
</lights>
```

That configuration was checked in `tile_1` (a `Tunnel Tile 2` at
(-18.1, 100, -10)): the Spot's beam lights the tunnel ahead and the
Rescue Randy mannequin at y = 104, and moves with the robot.

## Conversion notes

- The tunnel tiles reference their own meshes with `model://<sdf name>`
  URIs and some model.sdf files start with a blank line; the importer
  handles both (they were the two things this world needed beyond what
  the Urban import used).
- SDF lights have ranges from 8.7 m (staging area) to 20 m; the
  importer gives each lamp a flux proportional to range squared
  (40000 lm at 20 m by default), which keeps the staging area from
  blowing out under its dense point lights.
- Floors are at the tile origin height (`tile_1` floor at z = -10,
  measured through the collision mesh); tiles placed outside the
  connected map have no floor, so a robot spawned off a tile falls.
